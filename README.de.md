# Enigma-Plugins

[English](README.md) · [Deutsch](README.de.md)

Enigma2-Plugins für ARM-Receiver von Schrotty74. Jedes Plugin hat einen eigenen vollständigen Quellcode, eine Bauanleitung und einen Arbeitskontext für die Fortsetzung.

| Plugin | Kurzbeschreibung | Quellcode und Bauanleitung | Kontext |
|---|---|---|---|
| Box Systeminfo | Receiver-, Image-, Speicher-, CPU-, Netzwerk- und Tunerinformationen | [English](plugins/BoxSystemInfo/README.md) · [Deutsch](plugins/BoxSystemInfo/README.de.md) · [Build](plugins/BoxSystemInfo/BUILDING.md) | [Projekt](context/BoxSystemInfo/PROJECT_CONTEXT.md) · [Nächste Schritte](context/BoxSystemInfo/NEXT_STEPS.md) · [Agentenregeln](context/BoxSystemInfo/AGENTS.md) · [Chatvorlage](context/BoxSystemInfo/CHAT_TEMPLATE.md) |

Box Systeminfo 0.1.9 wurde auf dem Receiver getestet; die Anzeige der Daten wurde bestätigt. Der Nutzer hat die Veröffentlichung des [IPK](https://github.com/Schrotty74/Enigma-Plugins/releases) freigegeben. Die stabile Version ist 0.1.9; der Quellcode-Tag heißt `boxsysteminfo-v0.1.9`.

Der Plugin-Code steht unter MIT. Für eingebettete Drittprogramme und Laufzeiten gelten die jeweils mitgelieferten Lizenztexte. Originalquellen und Build-Skripte sind im Repository enthalten.
